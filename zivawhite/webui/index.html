Stored in this browser only, sent as a Bearer token to this server's own API. Voice in this page uses your browser's speech recognition. In Chrome and Edge that audio is processed by the browser vendor's cloud service, so it is not private or offline. For fully offline voice with wake words, enable the local voice loop (voice.enabled in configs/ziva.local.yaml; see README).
Ask anything, or give a command: volume up, open calculator, set a timer for 10 minutes, what time is it. Commands are matched by a fixed grammar and run on the machine this server runs on; everything else goes to the model. The meta line under each answer says which part produced it. Press the mic, or turn on hands-free and say a wake word.
